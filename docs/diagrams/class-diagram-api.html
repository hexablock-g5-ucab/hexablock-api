Lectura del UML

Selecciona una clase para seguir sus relaciones. Las líneas continuas con triángulo indican herencia; las discontinuas con triángulo, implementación. La flecha abierta indica asociación (continua) o dependencia (discontinua). El rombo vacío representa agregación. La multiplicidad y el propósito se detallan para cada conexión.
